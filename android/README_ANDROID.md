# चारा टंचाई सर्वेक्षण प्रणाली — Android मोबाईलवर वापरण्याची संपूर्ण मार्गदर्शिका

ही प्रणाली Android मोबाईलवर वापरण्यासाठी खालील **३ सोपे पर्याय** उपलब्ध आहेत:

---

## 🌟 पर्याय १: सर्वात सोपा — PWA मोबाईल ॲप (WiFi / हॉटस्पॉटद्वारे) [शिफारस केलेला]

या पद्धतीमध्ये मोबाईलवर काहीही इन्स्टॉल करावे लागत नाही. मोबाईलच्या Chrome ब्राउझरमध्ये १-क्लिक करून ॲप थेट फोनच्या होम स्क्रीनवर इन्स्टॉल होते!

### पायऱ्या:
1. **संगणकावर सर्व्हर सुरू करा**:
   PowerShell मध्ये कमांड चालवा:
   ```powershell
   cd "D:\chara-survey-automation-phase1-2\chara-survey-automation"
   .\.venv\Scripts\Activate.ps1
   python -m app.app
   ```
2. **मोबाईल व संगणक एकाच Wi-Fi किंवा मोबाईल हॉटस्पॉटवर कनेक्ट करा.**
3. **तुमच्या संगणकाचा IP ॲड्रेस पहा** (उदा. `10.35.212.241` किंवा `192.168.x.x`).
4. **Android मोबाईलमध्ये Chrome ब्राउझर उघडा** आणि टाईप करा:
   ```
   http://10.35.212.241:5000
   ```
5. **मोबाईल ॲप म्हणून सेव्ह करा (Install PWA)**:
   * Chrome च्या उजव्या बाजूला असलेल्या ३ डॉट्स (⋮) वर क्लिक करा.
   * **"Add to Home screen" (किंवा "Install App")** वर क्लिक करा.
   * तुमच्या मोबाईलच्या स्क्रीनवर **"चारा सर्व्हे"** नावाचे ॲप आयकॉन तयार होईल.
   * आता तुम्ही ते सामान्य Android ॲपसारखे फुलस्क्रीनमध्ये वापरू शकता!
6. **मोबाईल कॅमेरा सपोर्ट**:
   * "बल्क अपलोड" पेजवर **"कॅमेरा"** बटण दिले आहे, ज्यावर क्लिक करून तुम्ही थेट मोबाईल कॅमेऱ्याने कागदी सर्व्हेचा फोटो काढून लगेच AI द्वारे डेटा भरू शकता!

## 🚀 पर्याय २: थेट Android फोनमध्ये चालवणे (Termux द्वारे — संगणकाशिवाय)

जर तुम्हाला संगणकाशिवाय **केवळ आणि केवळ Android मोबाईलवरच** संपूर्ण Python सिस्टीम चालवायची असेल:

1. **Termux इन्स्टॉल करा**:
   * Google Play Store वरून नाही, तर [F-Droid (Termux)](https://f-droid.org/packages/com.termux/) वरून अधिकृत Termux ॲप डाऊनलोड करा.
2. **प्रोजेक्ट फाईल्स मोबाईलमध्ये कॉपी करा** (Download किंवा Termux होम फोल्डरमध्ये).
3. **Termux उघडून खालील कमांड चालवा**:
   ```bash
   bash android/setup_termux.sh
   ```
4. **ॲप सुरू करा**:
   ```bash
   bash android/run_app.sh
   ```
5. मोबाईलमधील कोणत्याही ब्राउझरमध्ये **`http://localhost:5000`** उघडा. संपूर्ण सिस्टीम इंटरनेट कनेक्शनसह मोबाईलवरच चालेल!

## 🌐 पर्याय ३: इंटरनेटवरून कुठूनही वापरण्यासाठी (Cloudflare Tunnel)

जर अधिकारी किंवा कर्मचारी फील्डवर (गावागावात) असतील आणि त्यांना मोबाईल 4G/5G वरून संगणकातील ॲप वापरायचे असेल:

1. मोफत **Cloudflare Tunnel** किंवा **ngrok** वापरा:
   ```powershell
   cloudflared tunnel --url http://127.0.0.1:5000
   ```
2. तुम्हाला एक सुरक्षित लिंक मिळेल (उदा. `https://chara-survey.trycloudflare.com`).
3. ही लिंक कोणत्याही Android मोबाईलवर उघडल्यास संपूर्ण महाराष्ट्रातून कर्मचारी थेट मोबाईलवर सर्व्हे फॉर्म भरू शकतात व Google Form मध्ये सबमिट करू शकतात.
